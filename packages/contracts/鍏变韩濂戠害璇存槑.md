# Shared Contracts

该目录存放跨语言稳定契约。后端 dataclass、API OpenAPI models 和前端 TypeScript types 都应由这些 schema 对齐或生成。

## Current schemas

- `action-proposal.schema.json`
- `tool-result.schema.json`
- `event-envelope.schema.json`
- `state-snapshot.schema.json`

项目特定 action payload schema 放在对应 extension 下，不应不断向通用 envelope 增加领域字段。

## Versioning

- 向后兼容字段新增：minor version；
- 删除、改名或语义变化：major version；
- event log 必须保存 schema version；
- frozen study bundle 必须固定 contract version。
